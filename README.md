Pokémon Game App is a React application built with Vite, featuring:
A homepage with Pokémon listings fetched from the PokeAPI.
Detailed stats and type information for each Pokémon.
A battle system that calculates outcomes based on stats and type advantages.
This lightweight app delivers a fast, responsive, and fun Pokémon experience for fans!
